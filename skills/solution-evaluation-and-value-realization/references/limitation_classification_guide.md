# Limitation classification guide

Classify limitations to avoid mixing different failure modes.

## Common limitation categories
- solution design limitation
- incomplete implementation
- process mismatch
- adoption or training limitation
- control or governance limitation
- data or measurement limitation
- dependency limitation
- unrealistic expectation or scope mismatch

## Guidance
A solution may appear weak because the measurement model is weak, not because the solution itself is failing. Keep those cases separate.
