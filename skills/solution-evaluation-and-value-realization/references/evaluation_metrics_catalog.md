# Evaluation metrics catalogue

Use this reference to choose measures that reflect value, not just activity.

## Common evaluation dimensions
- speed / cycle time
- error or defect rate
- rework volume
- throughput
- visibility / decision latency
- compliance or control adherence
- user effort
- adoption and usage quality
- exception handling quality
- business outcome measures specific to the initiative

## Guidance
- Prefer measures that connect back to the original business need.
- Use both quantitative and qualitative evidence when necessary.
- Distinguish outcome metrics from activity metrics.
