# Non-functional requirement taxonomy

Use this reference to separate quality attributes from functional behavior.

## Common NFR categories
- performance
- availability
- reliability
- security
- privacy
- usability
- accessibility
- maintainability
- scalability
- interoperability
- auditability
- localization
- compliance

## Guidance
A statement is likely non-functional when it constrains how well, how safely, how reliably, or under what quality conditions the solution must operate, rather than what specific business action it performs.
