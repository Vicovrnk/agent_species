# Prioritization methods menu

Use named methods as selectable lenses, not mandatory defaults.

## Common methods
- RICE
- ICE
- WSJF
- MoSCoW
- Kano
- cost of delay framing

## Guidance
Choose the method based on the decision context:
- use lighter methods when evidence is weak;
- use sequencing-aware methods when dependencies matter strongly;
- avoid forcing numeric scoring when the inputs are mainly qualitative.
