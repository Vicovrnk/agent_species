# Trade-off analysis guide

Use trade-off framing when multiple change options are plausible.

## Common comparison dimensions
- value potential
- speed to implement
- operational burden
- change management load
- compliance or control risk
- technical complexity
- reversibility
- dependency on scarce resources

## Guidance
- Compare options against the business need, not against personal preference.
- Do not force numeric scoring when evidence is weak.
- Name what each option optimizes and what it sacrifices.
- If one option only looks better because assumptions are hidden, surface the assumptions explicitly.
