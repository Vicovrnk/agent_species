# Swarm Species

This repository is intended for publishing species created by the Evolution Master.

A species is an assembled agent configuration: its role, working identity, skills, instructions, constraints, and expected behavior. Each species describes more than a set of files. It defines a reproducible agent phenotype that can be studied, refined, and used as a foundation for new variants.

## Choosing A Species

Species should be selected through repository branches.

Each branch represents a separate species or a stable evolutionary line of a species. By switching to the relevant branch, you get the complete state of that species: its structure, instructions, skill packages, and supporting documents.

## Branch Guidelines

- Use `main` as an overview or navigation branch unless the repository description states otherwise.
- To study a specific species, switch to the corresponding branch.
- For experiments, create a separate branch from the selected species so stable versions and work-in-progress changes stay separate.

## Repository Purpose

This repository acts as a showcase for manually published demo variants of Swarm species created with the `Evolution Master` agent.
